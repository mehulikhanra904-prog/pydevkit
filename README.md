## 📌 About PyDevKit

**PyDevKit** is an open-source Python developer toolbox designed to provide small, useful utilities through a simple command-line interface (CLI).

The project is built with beginners in mind, while also providing a foundation that contributors can extend with new developer tools.

Instead of creating separate scripts for common tasks, PyDevKit aims to bring multiple utilities together into one lightweight Python toolkit.

### 🎯 Project Goals

- Make useful developer utilities accessible from one CLI.
- Keep the code simple and beginner-friendly.
- Encourage students and new developers to contribute to open source.
- Provide good examples of Python project structure.
- Practice testing, Git, GitHub, CI/CD, and collaborative development.
- Continuously expand the toolbox through community contributions.
