# 🐍 PyDevKit

A beginner-friendly Python developer toolbox containing useful command-line utilities.

PyDevKit is an open-source project designed to provide simple and practical tools while also giving developers an easy project to learn from and contribute to.

## ✨ Features

### 🧮 Calculator
Perform basic arithmetic operations:

- Addition
- Subtraction
- Multiplication
- Division
- Simple expression support

Examples:

```text
20+70
50-15
10*5
100/4
